SQL Employee Management System

About the Project

This is a beginner-level MySQL project created to practise SQL database management and queries.

Technologies Used

* MySQL
* SQL
* VS Code

Features

* Create a database
* Create an employee table
* Insert employee records
* Display all employee records
* Display specific columns
* Filter employees using WHERE
* Find employees by department and salary

Database Structure

Column	Data Type
employee_id	INT
name	VARCHAR(50)
age	INT
department	VARCHAR(50)
salary	INT

Concepts Practised

* CREATE DATABASE
* USE
* CREATE TABLE
* PRIMARY KEY
* AUTO_INCREMENT
* INSERT INTO
* SELECT
* WHERE

Learning Outcome

Practised basic MySQL commands and learned how to store, retrieve and filter employee information.
